# W7D3: CIA Chart Generation

## Plotly

Plotly is a Python visualization library used to create interactive charts.
I created a bar chart showing sales by category.

## ECharts

ECharts is a JavaScript charting library used for interactive charts in web applications.
I created a bar chart using HTML and JavaScript.

## Comparison

Plotly is convenient for Python-based data analysis and dashboards.
ECharts is useful for frontend web applications because it works directly with JavaScript.

## Recommendation

For a Python data analysis project, I would recommend Plotly.
For a web-based frontend dashboard, I would recommend ECharts.
