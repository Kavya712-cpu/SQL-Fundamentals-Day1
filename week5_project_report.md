# Week 5 Project: AI-Powered EDA on Teen Phone Addiction Dataset

## Objective

Perform an AI-powered exploratory data analysis using Python and automated EDA tools.

## Dataset

Teen Phone Addiction Dataset

## Tools Used

- Python
- Pandas
- Matplotlib
- AutoViz
- SweetViz
- Jupyter Notebook
- Git
- GitHub

## Key Insights

1. Daily phone usage varies significantly among students.
2. Academic performance shows noticeable variation across the dataset.
3. Automated EDA tools quickly identify data distributions and missing values.
4. SweetViz provides an interactive HTML report suitable for business users.
5. AutoViz generates detailed visualizations that help analysts explore data efficiently.

## Business Recommendation

Educational institutions can use these insights to monitor excessive phone usage and identify students who may benefit from awareness programs on balanced digital habits.
